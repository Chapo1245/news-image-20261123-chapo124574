A one-image front page summing up the world's news of **Monday 23 November 2026**:
COP31 collapses without a deal, Democrats win a 258-seat House majority,
Ukraine sinks a Russian warship in Libya, a Russian drone strike leaves 14
missing near Kyiv, an Indonesian factory fire leaves 7 dead and 50 missing,
and Iran strikes a US base and three tankers in the Gulf — plus 20 more
stories from every region and beat, a world map of the day's hot spots, and
a strip of the day's key numbers.

## The image

`entry.png` (1024×1024, drawn fresh from verified news reports — AP, Reuters,
BBC, DW, Yonhap, AFP — no photographs reproduced) is produced by `main.py`,
a Python 3.13 standard-library-only program that copies the image to
`$MAKEFUN_OUTPUT_DIR` (or `/output`). It runs twice and writes byte-identical
output, with no network access.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
